# NutriIA - Plataforma de Acompañamiento Nutricional Pediátrico y Accesibilidad LSM

NutriIA es una aplicación Android nativa diseñada para brindar acompañamiento nutricional infantil, soporte en planes de embarazo guiados por inteligencia artificial y herramientas de accesibilidad mediante reconocimiento de Lengua de Señas Mexicana (LSM).

## Características Principales

* **Detección de Alimentos por Visión:** Clasificación automatizada de ingredientes y evaluación nutricional utilizando modelos avanzados de visión e integración con bases de datos como Open Food Facts.
* **Análisis Pediátrico Personalizado:** Evaluaciones clínicas basadas en normativas oficiales de salud para lactantes, infantes y escolares.
* **Asistente Virtual IA:** Chatbot interactivo para resolver consultas de alimentación y nutrición infantil.
* **Accesibilidad LSM:** Clasificador Relacional 3D en tiempo real para interpretar señas del abecedario mediante cámaras móviles y la biblioteca MediaPipe.
